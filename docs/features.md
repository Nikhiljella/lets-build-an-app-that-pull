# Feature Docs

Every app feature must include a feature docs file.

## Convention

Each feature folder should contain:

```text
src/features/<feature-name>/FEATURE.md
```

The feature doc should cover:

- Purpose
- User workflow
- Data sources
- Backend/API dependencies
- Key frontend files
- Fallback behavior
- Known limitations
- Future improvements
